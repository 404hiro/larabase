# STG 決済確認チェックリスト

## 目的

Stripe Checkout を STG 環境で実際に回し、支援付きメッセージの決済フローが正しく動くことを確認する。

## 前提

- STG 環境にデプロイ済みであること
- Stripe の STG キーが設定済みであること
- クリエイター側に Stripe Connect アカウントが接続済みであること
- Webhook が STG 環境に登録済みであること

## 1. 画面確認

- [ ] メッセージ送信画面で差し入れを有効にできる
- [ ] 支援額を選択できる
- [ ] 支援額・手数料・クリエイター受け取り額の内訳が表示される
- [ ] 送信時に Stripe Checkout へ遷移する

## 2. 決済フロー確認

- [ ] Stripe Checkout で支払い画面が表示される
- [ ] テストカードで決済できる
- [ ] 決済成功時に成功画面へ戻る
- [ ] 決済キャンセル時にキャンセル画面へ戻る
- [ ] 決済失敗時に適切な状態へ遷移する

## 3. Webhook 確認

- [ ] `checkout.session.completed` が受信される
- [ ] メッセージの状態が `safe` へ更新される
- [ ] `MessagePayment` の状態が `paid` へ更新される
- [ ] `stripe_payment_intent_id` が保存される
- [ ] `paid_at` が保存される

## 4. 料金・手数料確認

- [ ] 支援額の 10% が手数料として扱われる
- [ ] クリエイター受け取り額が期待どおりになる
- [ ] 受け取り額の内訳が画面上で説明できる

## 5. 例外系確認

- [ ] キャンセル時にメッセージ状態が `payment_cancelled` になる
- [ ] 既に支払い済みの支払いに対して二重処理が起きない
- [ ] Webhook 再送時でも重複処理にならない

## 6. 運用確認

- [ ] 管理者・運用者が支援内容を追跡できる
- [ ] 受け取り額や手数料の記録が残る
- [ ] 問題発生時に再試行できる
